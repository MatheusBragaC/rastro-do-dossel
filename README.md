# Rastro do Dossel

Jogo de plataforma 3D com câmera lateral, feito em Unity para o trabalho de Game Development (Ciência da Computação, UVV, 2026/2). Nilo atravessa uma selva armadilhada para levar um aviso de rádio às comunidades do vale.

Esta versão é a **1ª entrega**: só o nível 1, com menu, pausa, falha e tela de conclusão parcial.

## Como abrir

- Unity **6000.0.80f1** com o template Universal 3D (URP).
- Abra esta pasta no Unity Hub (Add → Add project from disk).
- Cena inicial: `Assets/Scenes/Menu.unity`. O nível fica em `Assets/Scenes/Nivel1_TrilhaEncoberta.unity`.

## Controles

| Tecla | Ação |
|---|---|
| A / D ou ← / → | andar |
| Shift esquerdo | correr |
| Espaço | saltar |
| Ctrl esquerdo ou S | deslizar |
| E | interagir |
| R | reiniciar a fase |
| Esc | pausar |

## Pastas

- `Assets/Scripts`: código do jogo, com a documentação de cada função pedida no enunciado.
- `Assets/Audio`: efeitos sonoros gerados pela equipe com `Ferramentas/gerar_sons.py`.
- `Docs/GDD-Rastro-do-Dossel.md`: Game Design Document (v0.5).
- `Docs/catalogo-assets.html`: catálogo dos 70 assets do nível, com fonte e licença.
